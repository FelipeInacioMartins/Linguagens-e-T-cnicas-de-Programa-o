# 💻 Linguagens e Técnicas de Programação

Repositório destinado aos meus estudos, exercícios e projetos desenvolvidos durante a disciplina de **Linguagens e Técnicas de Programação**.

Aqui serão registrados os conhecimentos adquiridos ao longo do curso, desde os conceitos fundamentais de programação até a implementação de algoritmos e estruturas mais avançadas.

## 📚 Conteúdos

Durante o desenvolvimento deste repositório, serão abordados conceitos como:

* Variáveis e constantes
* Tipos de dados
* Operadores
* Entrada e saída de dados
* Estruturas condicionais
* Estruturas de repetição
* Vetores (arrays)
* Matrizes
* Funções
* Procedimentos
* Ponteiros
* Strings
* Estruturas de dados
* Algoritmos
* Boas práticas de programação

## 💻 Linguagens

A principal linguagem utilizada neste repositório será:

* **C**

Conforme novos conteúdos forem estudados, outras linguagens poderão ser adicionadas.

## 🛠️ Técnicas de Programação

Os exercícios e projetos têm como objetivo desenvolver habilidades como:

* Raciocínio lógico
* Resolução de problemas
* Desenvolvimento de algoritmos
* Organização e estruturação de código
* Uso de estruturas de controle
* Modularização
* Manipulação de dados
* Análise e correção de erros
